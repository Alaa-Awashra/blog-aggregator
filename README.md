# Gator

Gator is a command-line RSS feed aggregator built with TypeScript, PostgreSQL, Drizzle ORM, and Node.js.

It allows users to register accounts, add RSS feeds, follow feeds, continuously collect posts, and browse the latest posts from feeds they follow.

## Requirements

To run Gator you need:

- Node.js
- npm
- PostgreSQL
- A running PostgreSQL database
